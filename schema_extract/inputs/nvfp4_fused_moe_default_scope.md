# nvfp4_fused_moe 默认运行提取范围

版本：1。确认日期：2026-11-04。

本范围适用于同一来源快照中的 `candidate/solution.py::Model.forward` 及其实际调用的实现。提取固定源码按默认实现选择运行时可达的全部路径。

实现选择采用源码中各控制项的默认行为。不通过手动 `cfg/cfg2`、环境覆盖、诊断入口、实验开关或手工 ABI 选择非默认实现；仅靠这些非默认控制才能到达的分支不在本次提取范围内。默认入口实际执行的自动选择仍在范围内，包括自动零探测、PDL 的形状门、路由与形状选择、eager 执行、graph 建立与回放、缓存复用，以及这些过程中源码已有的 fallback 和错误出口。不能将已提交的工作抹去，或为错误出口补造恢复路径。

“默认运行”仅限制上述实现选择，不表示仅使用接口参数的默认值，也不表示仅覆盖固定样本。完整任务输入域仍由原 `problem/metadata.json`、`problem/input.py`、`problem/shape_range.json` 和 `problem/shape_cases.json` 共同确定；保留全部已声明的动态范围、关联约束、路由情况、输入内容及可选参数情况。固定的 10 个样本不是完整支持域，不因实现覆盖不足而收窄 Contract。

本文件与原形状范围材料一起作为新提取的 `scope` 输入冻结。不修改 kernel 源码，不追改原快照、旧产物或原批准身份，也不重新定义任务数学、输入输出或验收判据。
