# Synthetic scalar-copy source

Copy one FP32 scalar without conversion or arithmetic. An optional write_output
flag selects whether a scalar result is requested; a false flag returns Python
None. The one-role scheduling description in the fixtures is a synthetic design
used to assess document expression. This suite does not claim GPU execution or
measure a real kernel's mapping, performance, or external numerical comparator.

The normal result criterion is exact. A separate fixture preserves a declared
external atol=0.01, rtol=0.05 record with its formula and relative basis absent;
that fixture is a fixed-source extraction record, not new acceptance authority.
