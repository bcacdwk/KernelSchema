# 第三轮 Extract 裁定

本轮先独立阅读 Extract 总览、P2–P6、REVIEW、common 和执行器边界，再阅读第一轮两份评审、两份 medium 推演及其输入；另定向核对 ME-01～ME-03 涉及的源码和任务材料。只新增本报告，未修改正式方法、YAML、脚本或运行状态，未启动提取或批准阶段。

**结论：保留 P2 的现有调查步骤与止点，修改后续采用选择和定点返回的口径。** 两位 medium 均能完成给定限域推演，未遇到必须改文案才能继续的阻塞；这不支持扩充调查要求或重排三层写作。Extract medium 仍把“改变集合回 P4”和“改变重要选型回 P2”并列，并让 P4“确认两份集合”，说明第一轮识别的职责交叠确实会传到接手者。应消除这一交叠，而不是增加一次审批或削弱全文审阅。

最小修改范围为六份方法文件：`EXTRACT_SCHEMA.md`、P3、P4、P5、P6、`REVIEW.md`。P2 本页已经要求独立审定主要机制、具体代表、记录去处及重要疑点，可保持不变。common、P1、执行器对齐说明和两份工具手册无需改动；它们现有边界足以承接本轮文字调整。

## 统一分工与返回

P2 应能有据说明本次来源范围内的实际实例、主计算与重要数值路径、关键物化及输出形成、主要分配与协作，以及差异为何成为完整代表、轻量记录或未展开独立候选。它还要审定具体 root、有限完整集合、保留理由和会影响这些取舍的疑点。P3/P5 将所选实例的公式、对象、范围、动作和必要保证写完整；P4 把已识别差异绑定到真实基线，安排未写代表及实际内容依赖；P6 审最终全文并核对知识去向。正文写作仍可深入源码，并不要求 P2 提前完成所有动作。

后续 reviewer 从当前产物和固定源码独立建立理解，核实上述判断是否真实落地。它不沿用旧批准代替判断，也不因换了阶段就重新搜候选、重选 root 或要求为全部代表再写一轮取舍结论。

| 具体影响 | 处理归属 |
| --- | --- |
| 当前固定来源的事实表明原机制分类、root 身份或完整代表取舍错误 | 回 P2 修受影响判断；如改变完整集合，再由 P4 落实目录、登记和依赖，相关作者修正文。既有源码中的误读也能触发纠错，不要求先有源码版本变化。 |
| 已定位的关键关系仍无法核实，因而不能支持某项保留、降级、root 判断或任务必需范围的代表选择 | 先沿具体入口/关系定向核实。若仍须重新判断选择，回 P2 补该项研究并审定；指出缺少的关系及其影响。仅说“理由不充分”或“可能还有机制”不足以重选。当前已能确认判断而只缺证据定位时，由有权作者补齐记录。 |
| 已选机制的正文漏写或写错已知数值、生产者、handoff、寿命、限制或自身范围 | 由定义所在 P3/P5 作者修正；当前可写则直接完成本节点。先前正文缺失不能被当作源码中该机制不存在，也不能仅据缺文要求降级。修后仍审有效全文和真实使用者。P6 保持既有明确授权的限域修稿权限。 |
| 不改变取舍的文件登记、写作先后、未来依赖或其他节点安排变化 | 由 P4 调整相关安排。若实际原因改变代表取舍，先修 P2；P4 不以安排写作为由自行增加或替换代表。 |
| 本节点整区本地化，或改用已存在已审、真正相同的整区，且不影响其他任务安排 | 本 P5 核对完整上下文和引用图；P6 对齐实际引用摘要。provider 本地定义错误回定义处，正确但不适用则改使用节点。 |
| 普通目录增补，包括不改变现有取舍/任务义务的已研究但未展开独立候选 | P3 交 P4 落实；P5 用既有交接汇集，P6 集中更新并再审。独立候选照 common 说明独特机制及未展开理由，不自动扩增完整集合，也不假称局部。 |
| 共享 Contract 错误；真实任务或固定来源发生变更 | 前者回 P1 修唯一定义并复核受影响前提；后者保持手册的另建提取边界。 |

这个分工区分的是待修的判断与产物，不增加回执字段、固定报告或一套额外关卡。返回只修受影响处，未受影响代表和稿件保留。

## Design 边界与验收点

第一轮 Design 建议在起点点明 root、在交付段突出“先判断并存必要性，再展开其他完整方案”，可以作为两处简洁澄清；medium 的实际体验表明它们不是阻塞修复，无需扩大为新调查阶段。首条 root 可以在少数有依据路线比较中形成，不要求先证明最优或完成验证。必须保留 Design 已有逐层自检与待验证条件：它从给定 Contract、workload、目标和环境推导新方案，不承担 Extract 的固定源码完整机制调查、既有实现忠实收录或独立 P2 审定义务。

本轮验收只需核对以下结果，不新增测试或报告格式：

- P4/P5/P6 与 REVIEW 不再同时宣称 P2 已审定选择、又例行要求下游逐份重新裁决；改变取舍先修 P2，P4 负责落实和写作依赖。
- 有具体事实或关键关系缺口时仍能纠错；无需源码版本变化，也没有无具体关系的“理由不足”重选入口。
- 已确认机制的正文遗漏、证据定位、本节点共享和普通目录增补各自能正常推进；未展开独立候选不因被发现就占一个完整名额。
- reviewer 的当前有效全文、实际来源、全部使用上下文及 P6 全目录终审没有缩减；手工推演与正式阶段结论、现行方法与旧执行器能力继续分开。

需要主代理统一采用的实质边界只有一项：**P2 决定机制与代表取舍，P4 落实这些决定和写作安排。** 本报告不主张重排 P2，不以本次有限源码阅读批准 MoE 的正式完整集合。
