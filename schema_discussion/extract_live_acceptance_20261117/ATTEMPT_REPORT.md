主要耗时来源：

1. **Qwen/max 单次工作本身很长。** 常见写稿/独审耗时30–90分钟；FA4 P3首次写作120分钟超时，沿保稿续写又约86分钟。巡检频率不会加速这些调用。
2. **工具阻塞后重建了5次运行。** 源码与稿件保留，但新冻结不继承阶段批准，需要重新核源和审阅。正式参考稿交接降低了空白重写成本，没有免掉审批成本。
3. **内部回执和格式性门禁造成重复提交。** 13–22行证据范围、比较对象键名误填、approval交接过长等，使已完成的长调用无法直接被采纳；其中真实越文件尾、错误名称仍应拒绝，任意12行限制已在当前工具中删除。
4. **确有内容退修。** 例如FA4执行单元的来源依据、目录变体缺基线链接、QSA把硬件占位修改错误安排给P3。这些是有效审阅/检查，不能归咎为工具故障。
5. **监督方式低效。** 主代理及多个接续监督长时间约45秒轮询，产生大量状态噪声；没有足够早改用后台定时监督，也没有足够早收敛机械约束及重建成本。

本次不能证明 Qwen/max 是这一提取流程的合理默认性价比，也不能证明当前产品的原默认预算可直接完成此类算子。试跑后期使用的是显式增大的预算；产品默认值没有据完整实测重新定稿。
